# Branding draft

Updated: 6 November 2026. Status: applied to local v0.3.5 at the user's request.

## Preferred name

**RateAlign** is the current preferred candidate. It describes aligning the output sample rate with the resolved source format. Pronunciation: “rate align.”

An initial web search did not identify an exact-name product or repository. Trademark, domain, registry, and app-store availability have not been verified. This is not clearance to claim exclusive use.

**NadaShift** remains an alternative draft name.

## Logo direction

Concept 02: two stepped signal paths converge at the same level. Use restrained petrol teal and graphite. Preserve a recognizable one-color silhouette at tray sizes; refine the central separation before production use.

Saved reference: [logo concept 02](../assets/concepts/ratematch-logo-concept-02.png). Its RateMatch wordmark is part of the earlier concept and would need updating if RateAlign is adopted. Sample-rate and bit-depth numbers belong to supporting branding, not the small app icon.

## Current application

The previously released application is **RateMatch v0.3.4**. The user subsequently requested application of the agreed changes: local v0.3.5 uses **RateAlign** and a simplified production version of logo concept 02. The concept image remains a historical reference. No new repository rename, commit, tag or release is included in this implementation task.
