# RateMatch v0.3.4

- Adds a 480 × 88 logical-unit mini mode with artwork, title, artist, album, output format and status.
- Keeps the mini bar on top and supports dragging, expand-to-main and Escape-to-main.
- Distinguishes hardware clamping from exact matching; a tooltip shows resolved source, output and full status.
- Uses RateMatch branding and replaces the old LS icon with a petrol-teal signal-alignment mark.
- Retains internal application identifiers and data paths for compatibility.
- Adds architecture, privacy and usage documentation. GPL-3.0-only remains unchanged.

Numeric transitions on assets/brand.svg illustrate format switching; the actual application icon omits small text for legibility.
